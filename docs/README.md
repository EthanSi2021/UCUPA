# UCUPA documentation

Start with the [project introduction](../README.md) and the [local demo](prototype-demo.md).
The [run guide](../RUN.md) covers product hosts, development tools, and verification.

The [architecture authority manifest](architecture/README.md) is the sole index of normative
specifications and current implementation contracts. Some authoritative documents retain their
original Chinese text; this snapshot does not introduce an unaudited normative translation.

The [development plan](architecture/development-plan.md) records current scope and the next gate.
It does not define domain semantics or start an implementation task.

Superseded designs, frozen development rationale, private implementation journals, and the
original Git history are not included in this source snapshot. Current contracts retain their
behavioral rules; mentioning a predecessor does not restore its authority or compatibility paths.
